# 💰 Personal Finance Manager

A professional and user-friendly **Personal Finance Manager Web Application** designed to help users manage their income, expenses, transactions, and overall financial activities efficiently.

## 🚀 Features

* ➕ Add income and expense transactions
* ✏️ Edit existing transactions
* 🗑️ Delete transactions
* 📊 Calculate total income, expenses, and balance
* 🏷️ Categorize financial transactions
* 🔍 Search and filter transactions
* 📅 Track transactions by date
* 💾 Store financial data
* 📱 Responsive and user-friendly interface
* ⚡ Simple and efficient financial management

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and dynamic functionality
* **Local Storage** – Browser-based data storage

## ⚙️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your financial transactions.

## 🎯 Project Objective

The objective of this project is to develop a simple and efficient platform for managing personal finances while demonstrating practical knowledge of **frontend development, JavaScript, DOM manipulation, data management, and responsive web design**.
